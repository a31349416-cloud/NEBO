# NEBO v3 HYPER — Найгарніший сайт погоди 🌤️✨🚀

**v3 HYPER** — ще рівень вище. 3D tilt, SVG анімовані іконки, mesh градієнт, історія та фаворити.

## ✨ Фічі v3 HYPER
- 🔍 Пошук + історія 6 останніх + обране ♡ (localStorage)
- 🌀 3D tilt hero (perspective 1000px) + mesh canvas з рухомими орбами
- 🌤️ SVG іконки з анімаціями: сонце обертається, дощ капає, сніг падає, гроза блимає
- 📈 Chart.js графік + трек 24 год + delta vs вчора
- 📊 Порівняти 4 міста (Київ/Львів/Одеса/Буковель) — live
- 🗺️ Карта + AQI + прогрес дня + gauge вологості
- 🌓 Світла/темна тема, °C/°F, Lenis + GSAP

## 🛠 Стек
Tailwind, GSAP, Lenis, Chart.js, Leaflet, Open-Meteo (без ключа)
